3. LIDAR RENDERING UPGRADE
· 3DGS: ADDED AS A SEPARATE VIEWER (/lidar-splat), existing GL_POINTS LiDAR kept unchanged.
  USGS 3DEP points are turned into one isotropic Gaussian each (scale = mean distance to the
  3 nearest neighbours, colour = SH degree-0 from ASPRS class, opacity 0.92), the 3DGS
  initialisation step. No training/optimisation, so it is not a photoreal radiance field.
  Renderer: PlayCanvas Engine 2.23.0, device order WebGPU then WebGL2. WebXR immersive-vr
  "Enter VR" button, enabled only when the browser reports immersive-vr available.
  Local production build on this VM: 1,188,568 Gaussians (downtown Atlanta, GA_Statewide_B2_2018),
  WebGPU adapter refused -> WebGL2 fallback, ~10 FPS in SwiftShader, 0 errors, VR not available.
  NOT VERIFIED: the WebGPU path and the VR session (no GPU or headset on this VM).
· Not adopted from the attached runbooks: Gameleon/MCMC training (needs photos + GPU training),
  Streamed SOG LOD bundles, WebGPU timestamp queries, Vercel Drains (Hobby plan), gen_ai.*
  conventions (no LLM in this app), and the "Georgia Perimeter Wall" construction section
  (physical civil-engineering spec, not software in this repo).
· Metrics: 24 metric families defined (22 server/RUM + gaussian_splats_drawn,
  gaussian_splat_webgpu_ratio). Production /api/metrics returned 52 series before this change.
  Not padded to 7,000; series exist only where something is measured.
· Point size (map LiDAR, lib/ga-lidar-layer.ts): diameter cut from 0.7x to 0.45x the projected node
  point spacing, minimum 1 CSS px (was 1.5), caps 6 CSS px desktop (was 10) / 3 touch (was 4).
  Desktop requests one extra octree level (point budget unchanged at 5 M) so the smaller points close up.
· Splat size (/lidar-splat): Gaussian sigma = 0.4x the mean 3-neighbour distance, clamped 0.03-0.6 m
  (was 1.0x, 0.08-1.5 m).
· Not adopted from the two new attachments: SHARP-GS 8K binning, GPU tile radix sort (PlayCanvas
  already sorts internally), StreamingGS/MobileSplat, Flink+PDAL, WebGPU Inspector, the 562 MB -> 13.6 MB
  memory figure (other scenes), and the wall-widening / concrete-curing spec (not software in this repo).
· Performance Impact: NOT MEASURED ON A GPU. This VM renders with SwiftShader (CPU): 3.7 FPS mean,
  p95 frame 483 ms on /godseye-telemetry at 1600x1000. No before/after GPU numbers exist.
· Memory Reduction: none claimed. JS heap measured 104 MB used during the VM run.
· Latency Reduction: none claimed; not measured.
